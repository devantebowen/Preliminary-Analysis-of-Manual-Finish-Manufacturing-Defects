# Upload this project to GitHub

1. Extract the ZIP on your computer.
2. Create a repository named `Manufacturing_Defect_Analysis`.
3. Suggested description: `Power BI analysis of 3,150 manufacturing defect records using Pareto charts, production-line comparisons, and root cause investigation.`
4. Upload the **contents** of the extracted `Manufacturing_Defect_Analysis` folder so `README.md` is at the repository root. Uploading just the ZIP will not display the project as a normal repository.
5. Commit the files.
6. Add your original `.pbix` file to `reports/` when available and update the README link.
7. Link the repository from your portfolio project page.

Suggested topics: `power-bi`, `data-analysis`, `manufacturing`, `pareto-analysis`, `quality-improvement`, `portfolio-project`.

The Word report is preserved as supplied. Before sharing it as a polished portfolio download, renumber Figures 2–6 to 1–5 and update in-text references, change “Laboratory and Environment” to “Measurement and Environment,” and restore full source entries matching its citations. The repository README provides a separate portfolio summary.
